# Skedula 제품 구상

## 핵심 경험

Skedula를 열면 이미 시간이 정해진 일정, 기한 안에 끝내야 하는 일, 중요하거나 하고 싶어서 시간을 내고 싶은 일을 함께 보고 하루를 짤 수 있다.

시간표에는 먼 미래의 중요한 일이나 아직 시간을 정하지 않은 일이 드러나기 어렵다. 할 일 목록에는 실제 일정과 빈 시간이 한눈에 들어오기 어렵고, 마감과 중요도가 함께 드러나야 무엇부터 챙길지 판단하기 쉽다. Skedula는 이 두 문제를 오늘 화면에서 함께 다룬다.

## 제품 방향

- 첫 대상은 macOS 데스크톱이다. MacBook 화면의 가로 공간을 활용해 시간을 보여주는 영역과 할 일을 보여주는 영역을 함께 띄운다.
- Windows는 후속 배포 대상으로 고려한다. Python + PySide6는 두 운영체제에서 화면과 우선순위 로직을 공유하기 위한 기술 후보이며, 기존 앱은 Python, Pygame, PyQt5, SQLite를 사용한다.
- 제품의 핵심과 화면 배치를 함께 논의한 뒤 첫 데스크톱 구현 범위를 정한다.

## 오늘 화면

| 왼쪽 · 오늘 시간표 | 오른쪽 · 오늘 할 일 |
| --- | --- |
| 시작 시각이 정해진 일정과 내가 배정한 작업 시간을 시간순으로 표시한다. | 오늘로 고른 항목을 표시한다. 전체 할 일과 버킷리스트는 사이드바에서 연다. |
| 예를 들어 오후 3시 치과 예약과 오전 11시부터 한 시간 동안 할 문서 작업을 표시한다. | 예를 들어 오늘 하기로 고른 회신의 마감과 배정한 작업 시간을 함께 표시한다. |

사이드바에서 오늘·할 일·버킷리스트를 오간다. 오늘 화면에서 고른 일만 오른쪽에 두는 방식과 좌우 폭 비율은 검토 중이다. 전체 할 일에서는 급한 일과 마감이 먼 중요 과제를 발견할 수 있어야 한다.

## 계획하는 방식

- 할 일을 **오늘 할 일로 골라두기**와 **시간표에 직접 배치하기**를 모두 지원하는 방향이다.
- **마감**은 끝내야 하는 때이고, **작업 시간**은 실제로 일하기로 정한 때다. 같은 할 일에 둘 다 있을 수 있다. 예를 들어 17시까지 회신해야 하는 일을 11시 30분에 하도록 배치할 수 있다.
- 화면 간 상태를 공유하는 방식이 제안됐다. 예를 들어 시간표에 배치한 문서 작업을 완료하면 할 일 목록에도 완료가 반영된다.
- 버킷리스트에 모아 둔 항목도 꺼내서 오늘 할 일로 골라두거나 시간을 배정할 수 있는 흐름을 검토한다.

## 페이지 구성 초안

| 페이지 | 주로 하는 일 |
| --- | --- |
| 오늘 | 시간표와 할 일을 함께 보고, 오늘 할 일을 고르거나 작업 시간을 정한다. |
| 할 일 | 해야 할 일을 모아보고, 중요도와 마감을 관리한다. |
| 버킷리스트 | 하고 싶은 일을 모아두고, 행동으로 옮길 항목을 고른다. |

## 이어서 논의할 사항

- 오늘 화면의 버킷리스트에는 내가 고른 항목을 표시할지, 앱이 가끔 한두 개를 다시 보여줄지도 정한다.
- 마감 임박과 중요한 일의 그룹 안에서 어떤 순서로 보여줄지, 양쪽에 해당하는 일을 어디에 표시할지 정한다.
- 우선순위를 검증할 때는 마감 없는 중요 과제, 먼 마감의 중요 과제, 급하지만 덜 중요한 일, 시간이 정해진 일정, 버킷리스트를 함께 두고 비교한다. 항목이 위에 표시된 이유를 설명하고 사용자가 예상한 순서와 어긋나는 지점을 확인할 수 있어야 한다.

## 첫 피드백용 시안

[오늘 테스트 화면](../prototype/today.html)은 00시부터 24시까지 시간선에 맞춰 일정을 그린다. 빈 구간을 드래그해 할 일을 연결하거나 작업을 새로 만들 수 있다. 시간표는 15분 단위로 그린다. 시계판에서 시작·종료의 시 또는 분을 선택한 뒤 바늘을 클릭하거나 드래그해 조정한다. Chrome 독립 창과 날짜별 로컬 저장은 피드백용 구현이다.

### 중요도와 마감 실험

할 일의 제목을 눌러 숫자 중요도(시안은 1~10점, 기본 5점), 마감일, 선택적 마감 시각을 바꾼다. 목록은 제목 왼쪽 책갈피 아이콘 안에 점수를 표시한다. 점수가 높을수록 책갈피와 카드에 붉은 기가 더해진다. 마감까지 남은 시간이 짧을수록 더 진해지며, 시각을 지정하지 않은 마감은 해당 날짜의 끝을 기준으로 한다. 완료하면 강조를 해제한다. 마감이 있는 항목만 카드 오른쪽에 기한을 표시한다. 기존 낮음·보통·높음은 각각 1·5·10점으로 옮긴다. 마감이 지났거나 3일 안에 다가오면 별도 날짜 표시를 강조한다. 프로토타입은 미완료 항목을 오늘까지 마감, 3일 안에 마감, 나머지 순으로 묶어 정렬하고, 같은 그룹에서는 중요도, 마감일 순으로 비교한다. 완료 항목은 마지막에 둔다. 3일 경계와 정렬 순서는 피드백 대상이다.

### 작업 시간 입력 방식 비교

길이 슬라이더를 제거했다. [비교 창](../prototype/time-studies.html)에서 같은 오후 일정에 대해 Apple Calendar의 시간표 드래그, Material Design의 시계판, Calendly의 빈 시간 제시 방식을 응용한 세 시안을 시험한다. 각 시안은 같은 치과 예약을 고려하며 배정 결과는 비교 창 안에서만 유지한다. 피드백에 따라 시간표 그리기와 시계 편집을 오늘 화면에 함께 적용했다. 시계에서는 작업 길이 추천 버튼을 제거했다.

### 할 일 목록 레퍼런스

목록에는 정렬 규칙을 풀어 쓴 문장을 두지 않는다. 아래는 표시 방식을 비교하기 위한 실제 제품 사례다.

- [Things의 Today 화면](https://culturedcode.com/things/support/articles/4001304/)은 달력 일정과 오늘 할 일을 한 목록에서 구획으로 나눈다. [일정과 마감](https://culturedcode.com/things/support/articles/2803579/)은 각각 설정한다.
- [Todoist의 Today 화면](https://www.todoist.com/help/todoist/get-started/plan-your-day-with-the-today-view-UVUXaiSs)은 높은 우선순위 작업이 위에 모인 예를 보여준다. [중요도](https://www.todoist.com/help/articles/set-a-priority-in-todoist-Wy82Jp)는 네 단계의 색으로 구분한다.
- [Apple 미리 알림의 Mac 목록](https://support.apple.com/guide/reminders/add-or-change-reminders-remndc729e28/mac)은 중요도를 느낌표 개수로 표현하고, 선택한 항목에서 날짜와 플래그를 편집한다.

### 오늘 시간표의 밀도와 동시 일정

창 높이에 맞춰 약 10시간을 한눈에 보여 주고, 스크롤로 하루 전체를 탐색한다. 처음 열면 현재 시간대가 보이고, 시간표 안의 얇은 선이 분 단위로 이동한다. 스크롤바는 숨기며 트랙패드와 키보드로 하루 전체를 탐색한다. 시간이 겹치는 일정은 같은 시간선에서 열을 나누고, 앞 일정이 끝나는 시각에 바로 시작하는 일정은 같은 열을 쓸 수 있다.

### 일주일을 계획하는 기능 시안

‘주간’에서 날짜별 약속·이동·할 일 마감을 함께 확인하고, ‘메모함’에서 아이디어를 모아 나중에 분류하는 흐름을 시험한다.

| 기능 | 참고 사례 | 시안에서 할 수 있는 일 |
| --- | --- | --- |
| 날짜가 있는 약속 | [Apple Calendar 일정](https://support.apple.com/guide/calendar/add-modify-or-delete-events-icalwr13-events/mac) | 날짜·시작·종료를 지정하고 오늘 시간표와 주간 목록에서 수정한다. |
| 반복 일정 | [Apple Calendar 반복](https://support.apple.com/en-ie/guide/calendar/icl1018/mac) | 매일 또는 매주 반복하며 시리즈 전체를 편집·삭제한다. |
| 이동 시간 | [Apple Calendar 이동 시간](https://support.apple.com/guide/calendar/add-location-and-travel-time-to-events-icl43600/16.0/mac/26) | 직접 입력한 이동 시간을 약속 앞에 별도 블록으로 확보하고 작업 시간 겹침 검사에 포함한다. |
| 주간 보기 | [Todoist Upcoming](https://www.todoist.com/help/todoist/get-started/plan-your-week-with-the-upcoming-view-OKOg1mR8) | 월요일부터 일요일까지 약속·이동·마감을 훑고 각 날짜에 약속을 추가한다. |
| 빠른 메모함 | [Todoist Inbox](https://www.todoist.com/help/todoist/get-started/use-the-inbox-in-todoist-HwHvYErS) | 제목 한 줄만 기록하고 필요할 때 할 일이나 버킷리스트로 옮긴다. |

### 캘린더 탐색

사이드바의 캘린더 안에서 오늘·주간·월간을 전환한다. 월간에는 날짜별 약속과 마감을 요약하고, 날짜를 누르면 해당 주를 연다. 오늘 보기는 항상 실제 오늘로 돌아온다. 메모함·할 일·버킷리스트를 다녀오면 직전에 사용한 캘린더 보기가 유지된다.

캘린더 상단 여백에는 메모함에 남아 있는 글을 한 번에 하나 표시한다. 여러 개면 12초마다 바뀌며 읽거나 키보드로 접근할 때는 멈춘다. 메모를 누르면 메모함을 열고, 할 일이나 버킷리스트로 분류한 항목은 미리보기에서 빠진다. 메모가 없으면 여백으로 남는다.

작업 시간 시계는 12시간제를 사용한다. 시작·종료 각각의 오전/오후 표시를 눌러 전환하거나, 시침을 드래그해 11시와 12시 사이를 지나면 회전 방향에 따라 반일이 바뀐다. 시간표에서 그리는 작업 블록은 드래그 중에도 15분 눈금 사이를 보간하지 않고 곧바로 다음 눈금에 붙는다.
